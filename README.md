# Credit Wise Loan Prediction System

## Overview

The Credit Wise Loan Prediction System is a Machine Learning project designed to predict loan approval outcomes based on applicant information and financial characteristics.

The project uses data analysis, preprocessing, and Machine Learning classification algorithms to identify patterns associated with loan approval.

## Problem Statement

The problem statement document is included in `problem_statement.pdf`. It describes the project problem and its objectives.

## Objectives

- Analyze applicant and financial data.
- Perform data cleaning and Exploratory Data Analysis (EDA).
- Preprocess categorical and numerical features.
- Train and evaluate Machine Learning classification models.
- Compare model performance using appropriate evaluation metrics.

## How to Run the Project

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn scikit-learn jupyter
   ```

3. Start Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

4. Open `credit_wise_loan_system.ipynb` and run the notebook cells.
